使用说明　① 用电脑版 Chrome / Edge 打开本页面；② 点击「连接蓝牙」，在弹窗中选择 SmartWitch；③ 连接成功后静默建立数据通道（手表不再语音播报），数据每 0.5 秒自动刷新。
若浏览器提示「不是安全上下文」，可在本文件所在目录执行 python -m http.server 8000，再访问 http://localhost:8000/SmartWitch_BLE_Dashboard.html。
多人 / 手机查看　双击 relay/start-relay.bat 起中转服务；本机用 http://localhost:8099 当主机连蓝牙，其他人用 http://<本机IP>:8099 打开即可同步查看（iPhone 亦可，人数不限）。
BLE 协议　Service 6E400001 · 数据通知 6E400003 · 指令写入 6E400002（Nordic UART 兼容）
指令格式　screen:1 · key:left · key:right · audio:haode · audio:wozai · sync
